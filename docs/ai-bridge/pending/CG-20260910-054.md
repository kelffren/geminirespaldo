PROBLEM
After the previous movement-recovery pass, PvP still had narrow real response gaps in cancel handoff, combo cadence tolerance, contact confirmation, Shadow Step startup, and trap activation. Existing diagonal/8-way melee presentation is already present, so it was not reimplemented.

CONFIRMED_IN_GEMINI
Current main was re-read before edits. KeloInput owns semantic buffering; KeloPvPWorld owns PvP orchestration/aim; KeloMeleeProfiles owns declarative melee timings; KeloAbilityData owns ability action/delivery data. Existing melee visual manifest already contains 8 directions and perceptible hit/reaction presentation. Baseline values were basic/follow cancel .055/.060, combo windows .14/.15, comboTimeout .52, staggers .07/.08/.13, Shadow Step windup .045, Poison Trap armTime .50.

EXTERNAL_EVIDENCE
The strict deployed PvP judge already established low input latency, 8-way aim precision, movement while attacking, measurable hit reaction and stable mobile frame pacing. This pass therefore avoided adding new managers, camera shake, blur or additional VFX and concentrated on small response windows.

HYPOTHESIS
Slightly wider cancel/combo windows, modest but capped stagger confirmation, and reduced startup/arming latency will make PvP inputs feel less dropped and actions more immediate without altering damage, range, knockback, active movement commitment or client/server movement semantics.

PROPOSED_CHANGE
Implemented candidate: basic/follow cancel .070/.075; combo windows .17/.18; combo timeout .60; basic/follow/finisher stagger .085/.095/.15; Shadow Step windup .030; Poison Trap armTime .42. Added independent deterministic Agent-B gate and CI.

DO_NOT_ASSUME
Do not interpret wider timing windows as permission to increase damage, active movement, aim magnetism or crowd-control duration further. Do not duplicate 8-way direction logic; it already exists. Visual clutter, aim assist tuning, telegraph readability and fixed mobile UI remain separate gaps requiring their own visual A/B.

EXPERIMENT
Baseline -> candidate on current main. Agent B asserts exact values, conservative ceilings, unchanged gameplay identity, 60/90/120 Hz quantization and aggregate stagger budget <=340 ms. Existing cast movement parity, Foundation and docs audits run after it. Strict PvP Quality Judge independently ran deployed mobile Chromium on commit 509d567d1830a27fedddbbc0d7de165df826132a.
