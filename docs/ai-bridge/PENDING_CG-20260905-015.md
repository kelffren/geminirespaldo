### CONFIRMED_IN_GEMINI

Aseprite documentation supports explicit sprite pivots/slices and exported metadata, suggesting a future Character Sprite Contract can encode foot/pivot/contact semantics instead of inferring them from PNG pixels.

### HYPOTHESIS
Using frame 2 as the lateral stable-stop frame, while preserving a matching stride phase of 0.5, should make release look more planted than the frame-0 baseline without changing world movement, collision, camera, speed or stride distance. Keeping ?plantFrame=0 as an A/B override preserves a clean baseline.

### PROPOSED_CHANGE
Implemented MOV-PLANT-V1 in engine-ac.js: default plant frame 2, plant phase 0.5, stable idle/release resets to frame 2/phase 0.5, and the audit publishes plantFrame/plantPhase. A query override ?plantFrame=0..3 permits controlled A/B. A bug in the first selector used Number(null), which made an absent query parameter become 0; commit 80a93614ff51001489f569f03e4d1ee879ef5e22 corrects that by treating a missing parameter as NaN. scripts/live-movement-audit.mjs now expects frame2/phase0.5 and performs the same RIGHT -> LEFT reversal -> release trace.
