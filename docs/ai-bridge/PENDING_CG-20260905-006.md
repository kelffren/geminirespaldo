### PROBLEM
The live renderer still maps both lateral directions to sprite-sheet row 2 and mirrors that row for LEFT, while row 1 is unused. Previous rounds established that row semantics are unknown, so switching LEFT to row 1 by intuition would be unsafe. The current preprocessing audit measures crop/near-white behavior but still cannot quantify whether row 1 is actually related to row 2 as a direct or horizontally mirrored authored direction.

### EXTERNAL_EVIDENCE
- Aseprite official sprite-sheet documentation confirms matrix sheets are simply ordered collections of frames; row meaning must come from authored organization/tags rather than being inferred from matrix shape alone.
- Aseprite official tags/slices documentation supports explicit animation grouping and pivots, reinforcing that authored semantics are preferable when source metadata exists.
- Community counterevidence is mixed: mirroring left/right can be acceptable for symmetric characters, while asymmetric details can make authored opposite-direction frames materially better. Therefore similarity evidence can narrow the question but cannot alone prove semantic direction.

### HYPOTHESIS
If row 1 is an authored opposite lateral direction, its opaque RGBA content should have a measurable relationship to row 2. Comparing row 1 against row 2 both directly and frame-local horizontally mirrored, while excluding pixels where both samples are transparent, provides reproducible evidence without changing rendering. A strong mirrored relationship would support later manual inspection for authored LEFT; weak/no relationship would argue against blindly using row 1.

### DO_NOT_ASSUME
- Do not interpret higher mirrored similarity as proof that row 1 is LEFT. It is pixel evidence only.
- Do not switch row mapping without visual/manual confirmation of posture, feet, asymmetry and phase alignment.
- Do not infer CONTACT frames from row similarity.
- Do not change avatar scale, collider, camera, crop, knockWhite, shadow or gait in the same experiment.
- Exact RGBA equality is intentionally strict; palette/lighting differences can lower similarity even for semantically corresponding authored directions.

### EXPERIMENT
1. Let Pages deploy the commits containing audit v3.
2. Run the LIVE Playwright harness and collect `test-results/hero-audit.json`.
3. Record direct and mirrored row similarity plus compared-pixel count and preprocessMs.
4. Capture/crop all four row-1 and row-2 frames for visual inspection.
5. If mirrored similarity is materially stronger than direct similarity, inspect whether row 1 visually represents the opposite lateral direction and whether corresponding columns preserve leg phase.
6. If authored LEFT is confirmed, make a separate one-change A/B: LEFT mirrored row2 baseline -> LEFT row1 candidate, same movement trace, same footRoot/collision/camera invariants.
7. If row 1 is unrelated, keep current mirror and move to contact-frame/foot-plant audit instead of forcing a row mapping.

- The extra row comparison adds one-time preprocessing arithmetic; it does not add per-frame renderer work, but preprocessMs must be observed.
